## ADR 模板

创建新的ADR时，请使用以下模板：

```markdown
# ADR-XXXX: [决策标题]

## 状态
[提议中 | 已采用 | 已弃用 | 已替代]

## 背景
[描述促使做出此决策的情况和问题]

## 决策
[描述我们选择的解决方案]

## 后果
[描述决策的积极和消极后果]

## 替代方案
[描述考虑过的其他选项]

## 相关决策
[链接到相关的ADR]
```

## 决策原则

1. **可追溯性** - 所有重要的架构决策都应该被记录
2. **透明性** - 决策过程和理由应该清晰可见
3. **演进性** - ADR应该反映架构的演进过程
4. **实用性** - 专注于对项目有重大影响的决策

## 维护指南

- 新的架构决策应该创建新的ADR
- 现有ADR的状态变更应该更新索引
- 重大架构变更前应该先创建ADR进行讨论
- ADR应该在代码审查过程中被引用和验证
